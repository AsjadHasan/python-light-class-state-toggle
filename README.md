# python-light-class-state-toggle
A Python OOP exercise demonstrating state management using a Light class with turn_on(), turn_off(), and status() methods to control and track the light's ON/OFF state.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP)
2. Class and Object Creation
3. Constructor (__init__())
4. Instance Attributes
5. Boolean Data Type (True and False)
6. Instance Methods
7. State Management
8. Conditional Statements (if-else)
9. Encapsulation Basics
10. Changing and Tracking Object State
